# DataFlowBI 概览

DataFlowBI 是一个面向 CSV/XLSX 的数据分析平台，提供上传解析、统计报告、可视化分析、清洗与版本化、以及多格式报告导出。

## 核心能力

- 上传解析：CSV/XLSX 自动解析、字段预览、过滤信息生成
- 统计报告：缺失率、数值摘要、相关性、时间序列、异常值等
- 可视化：ECharts 懒加载，17+ 分析类别与图表类型
- 清洗增强：清洗模板、类型建议、质量评分、清洗前后对比、日志导出
- 版本管理：每次清洗生成新版本，支持历史加载与版本对比
- 报告导出：Word/PDF/PPTX（支持图表嵌入）、Excel（多表与格式增强）

## 混合持久化

- 默认：文件版本化（uploads 目录）+ 元数据入库（PostgreSQL，可选）
- 可选：启用自动入库，将数据版本写入 PostgreSQL 表
